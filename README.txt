Inabakumori Music Player UI
===========================

An interactive music player built using vanilla HTML, CSS, and JavaScript as practice project.

About
-----

Music player made with CSS, HTML & JS, has functional control buttons & CSS Variables that are change-ready,
So if you're planning to use this music player for your own project(yes, you, the reader) you can simply just change the
CSS variables in the :root {} but there are very few CSS properties I had to separate from the variables so just make sure 
to read the code.

The theme and aesthetic is centered around the artist/music producer Inabakumori (いなばくもり).

The website is inspired by "Animation Coding"'s Neumorphism Music player tutorial.
(https://youtu.be/z5x14F_jZzs?si=3I3F4lHvLnFoH0cU)

Anybody is free to use, change & customize the music player in any way their like in their own public/private projects.

Features
--------
• Liquid-glass / Neumorphism visual aesthetic with custom backdrop filters
• Full interactive audio controls (Play, Pause, Previous, Next, Seek/Progress Bar, and Stop/Reset)
• Dynamic playlist drawer generated directly from JavaScript array data
• Active track highlighting and position tracking
• Rotating album artwork animation timed to playback
• Custom typography stack supporting English (Google Sans) and Japanese (M PLUS Rounded 1c) characters
• Fully responsive, custom neumorphic and inset shadow sets managed via CSS Variables (`:root`)

Made using:
------------
- HTML5
- CSS3 
- Vanilla JavaScript
- Visual Studio Code
